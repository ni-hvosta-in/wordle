# Добро пожаловать в команду

Ты присоединяешься к разработке **Wordle Battles** на позиции Java-разработчика. Первая неделя — освоиться, поднять проект и закрыть первую задачу. Регламент работы описан в [CONTRIBUTING.md](../CONTRIBUTING.md).

## О продукте

Словесная игра для тренировки английского по уровням CEFR (A1–B2).

**Что есть сейчас:**
- **Слово дня** — одно слово на всех, играть можно без регистрации.
- **Личная игра** — бесконечная цепочка слов своего уровня, есть подсказки и монеты.

**Куда идём в этом квартале: мультиплеер.**
1. Вызов другу по ссылке: оба играют одно слово, потом сравниваем результат.
2. Поиск случайного соперника.
3. Дуэли в реальном времени и рейтинг.

**Дальше:** режим учителя (класс играет турниры, учитель видит статистику) и Telegram Mini App. Это основа монетизации.

## Архитектура (как есть)

```
frontend (React + TS, Vite)  ──HTTP/JSON──▶  backend (Spring Boot 4, Java 17)  ──JPA──▶  PostgreSQL 15
                                              │
                                              ├─ auth/       регистрация, логин, JWT
                                              ├─ game/common  проверка слова, словари, стратегии режимов
                                              ├─ game/daily   слово дня
                                              ├─ game/personal личная игра, подсказки, прогресс
                                              └─ common/      JWT-фильтр, обработка ошибок, JMX-метрики
```

Что важно знать:
- **Режимы игры** сделаны через паттерн «Стратегия» (`GameModeStrategy`). Новый режим — новая стратегия. На этом будет строиться мультиплеер.
- **Словари** — txt-файлы в `backend/src/main/resources/words/`, загружаются в память при старте.
- **Авторизация** — самописный `JWTFilter`. Сейчас он защищает только `/game/personal/**`.
- **Известный техдолг:** ход игры хранится в памяти (`GameSessionService`), пароли не захешированы, нет миграций БД и тестов. Всё это задачи первого спринта: ты будешь это чинить.
